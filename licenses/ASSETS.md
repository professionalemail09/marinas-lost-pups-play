# Marina's Lost Pups: art and asset provenance

This file lists third-party and original assets shipped in the web game. Park photograph
credits (author, licence, source URL) live in `assets/parks/CREDITS.md`. Licence texts are
in this folder. A short notices list is in `THIRD_PARTY_NOTICES.txt`.

| Asset | What it is | Source / licence |
|---|---|---|
| `assets/parks/ph-01.jpg` … `ph-63.jpg` | Park Hunt photographs (63 U.S. national parks). Neutral file names; no on-screen credit during a question. | Public domain or CC0. Full table: `assets/parks/CREDITS.md` |
| `assets/terrain/*.webp` | Country / territory terrain images for geography modes | Natural Earth, public domain. See `assets/terrain/CREDITS.md` |
| `marina_face.webp`, `logo.webp` | Marina portrait and title logo | Original art for this game |

| In-game characters, UI, flags and effects | Vector / canvas drawings in code | Drawn procedurally in the game's own source (flags from geometric specs; no flag image files) |
| `fonts/fredoka.woff2` | Fredoka | SIL OFL 1.1: `OFL-Fredoka.txt` |
